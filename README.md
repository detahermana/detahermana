### Hi, I'm Deta 👋

I build and operate infrastructure — infrastructure as code, CI/CD pipelines
that keep deployment credentials out of reach, and self-hosted observability
and security stacks.

I care about the reasoning behind a system as much as the system itself. Most
of what I publish documents *why* a choice was made, not just what it does —
because a configuration without its rationale is only half useful to the next
engineer.
